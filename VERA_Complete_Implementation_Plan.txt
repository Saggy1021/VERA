WHAT VERA IS:
  VERA is a FastAPI WebSocket server that receives a live webcam/audio feed
  from a browser client and runs a parallelized pipeline of AI models to
  detect behavioral anomalies during online exams and interviews.

  It uses:
    - MediaPipe FaceMesh   → gaze direction, head pose, eye contact
    - DeepFace             → emotion detection (7 classes)
    - YOLOv8 (ONNX)        → unauthorized object detection (phone, book, laptop)
    - OpenAI Whisper       → speech transcription
    - Silero-VAD           → voice activity detection
    - SpeechBrain ECAPA    → speaker verification (detects coaching)
    - InsightFace ArcFace  → identity enrollment and verification
    - MiniFASNet ONNX      → liveness / anti-spoofing

  The frontend dashboard sends video frames + audio chunks over WebSocket.
  The server runs all models in parallel threads and returns a JSON blob every
  ~500ms with behavioral scores, flags, and risk assessment.

  2. Remove `_has_yolo` and `self.yolo_model`.
  3. Add onnxruntime InferenceSession to load vera/models/yolov8s.onnx.
  4. Add ONNX preprocessing: resize to 640×640, normalize to float32 [0,1],
     transpose to NCHW format (shape: [1, 3, 640, 640]).
  5. Add ONNX output parsing: raw output is shape [1, 84, 8400].
     - Transpose to [8400, 84]
     - Columns 0-3: cx, cy, w, h (center + size format)
     - Columns 4-83: class scores for 80 COCO classes

  import os
  import cv2
  import numpy as np
  import onnxruntime as ort
  import threading
  import logging

  logger = logging.getLogger(__name__)

  COCO_CLASSES_OF_INTEREST = {63: 'laptop', 67: 'cell phone', 73: 'book'}
  MODEL_PATH = os.path.join(os.path.dirname(__file__), 'models', 'yolov8s.onnx')
  CONFIDENCE_THRESHOLD = 0.45

  class EnvironmentDetector:
      def __init__(self):
          self._lock = threading.Lock()
          self._result = {'objects_detected': [], 'flag': False}
          self._has_onnx = False

          if not os.path.exists(MODEL_PATH):
              logger.warning(
                  f"YOLOv8 ONNX model not found at {MODEL_PATH}. "
                  "Run manual export step first. Environment detection disabled."
              )
              return

          try:
              self.session = ort.InferenceSession(
                  MODEL_PATH,
                  providers=['CPUExecutionProvider']
              )
              self.input_name = self.session.get_inputs()[0].name
              self._has_onnx = True
              logger.info("EnvironmentDetector: YOLOv8 ONNX loaded successfully.")
          except Exception as e:
              logger.error(f"EnvironmentDetector: Failed to load ONNX model: {e}")

      def _preprocess(self, frame):
          img = cv2.resize(frame, (640, 640))
          img = img.astype(np.float32) / 255.0
          img = img.transpose(2, 0, 1)          # HWC → CHW
          img = img[np.newaxis, ...]             # CHW → 1CHW (batch=1)
          return img

      def _postprocess(self, outputs, orig_h, orig_w):
          raw = outputs[0][0]                    # shape: [84, 8400]
          raw = raw.T                            # shape: [8400, 84]

          detected = []
          for row in raw:
              class_scores = row[4:]
              class_id = int(np.argmax(class_scores))
              confidence = float(class_scores[class_id])

              if confidence < CONFIDENCE_THRESHOLD:
                  continue
              if class_id not in COCO_CLASSES_OF_INTEREST:
                  continue

              cx, cy, w, h = row[0], row[1], row[2], row[3]
              # Scale from 640×640 back to original frame size
              x1 = int((cx - w / 2) * orig_w / 640)
              y1 = int((cy - h / 2) * orig_h / 640)
              x2 = int((cx + w / 2) * orig_w / 640)
              y2 = int((cy + h / 2) * orig_h / 640)

              detected.append({
                  'class': COCO_CLASSES_OF_INTEREST[class_id],
                  'confidence': round(confidence, 3),
                  'bbox': [x1, y1, x2, y2]
              })

          return detected

      def analyze(self, frame):
          """Call this from vera_pipeline.py with a BGR numpy frame."""
          if not self._has_onnx:
              return {'objects_detected': [], 'flag': False}

          orig_h, orig_w = frame.shape[:2]
          inp = self._preprocess(frame)
          outputs = self.session.run(None, {self.input_name: inp})
          detected = self._postprocess(outputs, orig_h, orig_w)

          result = {
              'objects_detected': detected,
              'flag': len(detected) > 0,
              'flag_reason': [d['class'] for d in detected] if detected else []
          }
          with self._lock:
              self._result = result
          return result

      def check(self):
          """Returns last result. Thread-safe."""
          with self._lock:
              return dict(self._result)

[MODIFY FILE] vera/deception_scorer.py

CONTEXT: The current deception_scorer.py fires instant +75 or +100 score
jumps on single events (tab-switch, screen share loss). This is the #1 source
of false positives. A single dropped frame can permanently destroy a
candidate's score. This must be replaced with an EWMA (Exponentially Weighted
Moving Average) temporal accumulator with a persistence gate.

THE PROBLEM WITH THE OLD LOGIC (DO NOT USE):
  # BAD — never do this:
  if tab_switch_detected:
      score += 75   # ← instant catastrophic jump, no confirmation required
  if screen_share_lost:
      score += 100  # ← nuclear option from a single dropped frame

THE CORRECT ARCHITECTURE:
  Every behavioral signal contributes a raw_signal value (0.0 to 1.0).
  Signals are fed into an EWMA smoother that dampens transient spikes.
  A signal only contributes to the risk score if it persists for at least
  N seconds (the persistence gate). This eliminates single-frame false positives.

IMPLEMENTATION — replace deception_scorer.py entirely:

  import time
  import threading
  import logging
  from collections import deque

  logger = logging.getLogger(__name__)

  # ── EWMA Configuration ──────────────────────────────────────────────────────
  EWMA_ALPHA = 0.3          # Smoothing factor. Lower = slower reaction, fewer FP.
                             # 0.3 is validated for ~500ms pipeline tick rate.
  PERSISTENCE_GATE_SECONDS = 5.0   # A signal must persist this long to fully count.
  SCORE_DECAY_PER_SECOND = 0.5     # Risk score decays when no signals are active.

  # ── Signal Weights (raw contribution to risk score, 0.0–1.0) ───────────────
  # These are the maximum contribution each signal can make AFTER temporal
  # confirmation. No single signal can cause a catastrophic jump.
  SIGNAL_WEIGHTS = {
      'gaze_away':              0.15,   # Looking away from screen
      'head_turned':            0.15,   # Head rotated > threshold
      'multiple_faces':         0.35,   # Second person in frame (high confidence)
      'unauthorized_object':    0.25,   # Phone/book/laptop detected
      'emotion_distress':       0.10,   # Extreme fear/surprise/contempt
      'audio_mismatch':         0.20,   # Lip movement ≠ audio
      'second_speaker':         0.40,   # Different voice than enrolled baseline
      'tab_switch':             0.20,   # Focus loss (windowed — NOT instant +75)
      'screen_share_lost':      0.15,   # Stream interruption (NOT instant +100)
      'no_face_detected':       0.30,   # Face not visible for extended period
      'identity_mismatch':      0.50,   # InsightFace says different person
  }

  class SignalAccumulator:
      """
      Tracks a single behavioral signal with EWMA smoothing and persistence gate.
      A signal must persist for PERSISTENCE_GATE_SECONDS before it fully
      contributes to the risk score.
      """
      def __init__(self, name: str, weight: float):
          self.name = name
          self.weight = weight
          self._ewma = 0.0
          self._first_seen: float | None = None
          self._last_update = time.monotonic()

      def update(self, raw_value: float) -> float:
          """
          Feed a raw signal value (0.0 = no signal, 1.0 = strong signal).
          Returns the gated, weighted contribution to risk score.
          """
          now = time.monotonic()
          # EWMA smoothing
          self._ewma = EWMA_ALPHA * raw_value + (1 - EWMA_ALPHA) * self._ewma

          # Persistence gate
          if self._ewma > 0.3:
              if self._first_seen is None:
                  self._first_seen = now
              persistence = min(1.0, (now - self._first_seen) / PERSISTENCE_GATE_SECONDS)
          else:
              self._first_seen = None
              persistence = 0.0

          self._last_update = now
          return self._ewma * persistence * self.weight

      def reset(self):
          self._ewma = 0.0
          self._first_seen = None


  class DeceptionScorer:
      """
      Aggregates all behavioral signals into a single 0–100 risk score.
      Uses EWMA + persistence gating. No instant score jumps.
      """
      def __init__(self):
          self._lock = threading.Lock()
          self._accumulators = {
              name: SignalAccumulator(name, weight)
              for name, weight in SIGNAL_WEIGHTS.items()
          }
          self._risk_score = 0.0
          self._active_flags: list[str] = []
          self._last_tick = time.monotonic()

          # Severity thresholds for the dashboard
          self.THRESHOLD_LOW    = 25.0
          self.THRESHOLD_MEDIUM = 50.0
          self.THRESHOLD_HIGH   = 75.0

      def update(self, signals: dict) -> dict:
          """
          Feed the latest pipeline output into all accumulators.

          Args:
              signals: dict mapping signal names to raw values (0.0–1.0).
                       Only include signals that are currently active.
                       Absent signals are treated as 0.0 (no activity).

          Returns:
              dict with risk_score, severity, active_flags, per_signal breakdown.
          """
          now = time.monotonic()
          elapsed = now - self._last_tick
          self._last_tick = now

          total_contribution = 0.0
          active_flags = []
          breakdown = {}

          with self._lock:
              for name, acc in self._accumulators.items():
                  raw = float(signals.get(name, 0.0))
                  contribution = acc.update(raw)
                  breakdown[name] = round(contribution, 4)
                  total_contribution += contribution
                  if contribution > 0.05:   # Flag threshold — above noise floor
                      active_flags.append(name)

              # Convert total contribution to 0–100 score
              # Max possible contribution is sum of all weights ≈ 2.75 → maps to 100
              max_possible = sum(SIGNAL_WEIGHTS.values())
              raw_score = (total_contribution / max_possible) * 100.0

              # Score decay when nothing is active
              if not active_flags:
                  self._risk_score = max(
                      0.0,
                      self._risk_score - SCORE_DECAY_PER_SECOND * elapsed
                  )
              else:
                  # Smooth score increase (no instant jumps)
                  self._risk_score = EWMA_ALPHA * raw_score + (
                      1 - EWMA_ALPHA
                  ) * self._risk_score

              self._risk_score = min(100.0, max(0.0, self._risk_score))
              self._active_flags = active_flags

              severity = self._get_severity(self._risk_score)

              return {
                  'risk_score': round(self._risk_score, 2),
                  'severity': severity,
                  'active_flags': active_flags,
                  'breakdown': breakdown,
                  'timestamp': now
              }

      def _get_severity(self, score: float) -> str:
          if score >= self.THRESHOLD_HIGH:
              return 'HIGH'
          elif score >= self.THRESHOLD_MEDIUM:
              return 'MEDIUM'
          elif score >= self.THRESHOLD_LOW:
              return 'LOW'
          return 'CLEAN'

      def reset(self):
          """Call this at session start/end to clear all state."""
          with self._lock:
              for acc in self._accumulators.values():
                  acc.reset()
              self._risk_score = 0.0
              self._active_flags = []

      def get_current(self) -> dict:
          """Thread-safe read of last computed score."""
          with self._lock:
              return {
                  'risk_score': round(self._risk_score, 2),
                  'severity': self._get_severity(self._risk_score),
                  'active_flags': list(self._active_flags)
              }

PURPOSE: Enroll a candidate's face during the setup wizard, then verify their
identity on every pipeline tick. Uses InsightFace ArcFace (MIT) for embedding
comparison and MiniFASNet (Apache 2.0) for liveness/anti-spoofing detection.

  import os
  import numpy as np
  import cv2
  import onnxruntime as ort
  import threading
  import logging

  logger = logging.getLogger(__name__)

  MINIFASNET_MODEL_PATH = os.path.join(
      os.path.dirname(__file__),
      'models', 'MiniFASNet',
      '2.7_80x80_MiniFASNetV2.onnx'
  )
  COSINE_THRESHOLD = 0.4   # Below this = identity mismatch

  try:
      import insightface
      from insightface.app import FaceAnalysis
      _has_insightface = True
  except ImportError:
      _has_insightface = False
      logger.warning("insightface not installed. Identity verification disabled.")


  class IdentityVerifier:
      """
      Provides face enrollment + verification + liveness detection.
      Enrollment happens once during the setup wizard.
      Verification runs every pipeline tick.
      """

      def __init__(self):
          self._lock = threading.Lock()
          self._enrolled_embedding: np.ndarray | None = None
          self._ready = False

          if not _has_insightface:
              return

          try:
              self._app = FaceAnalysis(
                  name='buffalo_sc',                      # Lightweight model, MIT
                  providers=['CPUExecutionProvider']
              )
              self._app.prepare(ctx_id=0, det_size=(640, 640))
              self._ready = True
              logger.info("IdentityVerifier: InsightFace loaded.")
          except Exception as e:
              logger.error(f"IdentityVerifier: InsightFace init failed: {e}")

          # Load MiniFASNet liveness model
          self._liveness_session = None
          if os.path.exists(MINIFASNET_MODEL_PATH):
              try:
                  self._liveness_session = ort.InferenceSession(
                      MINIFASNET_MODEL_PATH,
                      providers=['CPUExecutionProvider']
                  )
                  logger.info("IdentityVerifier: MiniFASNet liveness model loaded.")
              except Exception as e:
                  logger.warning(f"IdentityVerifier: Liveness model failed: {e}")
          else:
              logger.warning(
                  f"MiniFASNet model not found at {MINIFASNET_MODEL_PATH}. "
                  "Run MANUAL STEP 2 from the implementation plan."
              )

      def enroll(self, frame: np.ndarray) -> dict:
          """
          Extract and store a face embedding from the enrollment frame.
          Call this once during the setup wizard after the candidate is seated.
          Returns: {'success': bool, 'message': str}
          """
          if not self._ready:
              return {'success': False, 'message': 'InsightFace not available.'}

          faces = self._app.get(frame)
          if not faces:
              return {'success': False, 'message': 'No face detected in enrollment frame.'}
          if len(faces) > 1:
              return {'success': False, 'message': 'Multiple faces detected. Ensure only one person is visible.'}

          with self._lock:
              self._enrolled_embedding = faces[0].embedding.copy()

          logger.info("IdentityVerifier: Candidate enrolled successfully.")
          return {'success': True, 'message': 'Identity enrolled.'}

      def verify(self, frame: np.ndarray) -> dict:
          """
          Compare the face in the current frame against the enrolled embedding.
          Returns: {'verified': bool, 'similarity': float, 'mismatch': bool,
                    'liveness': bool, 'no_face': bool}
          """
          if not self._ready:
              return {'verified': True, 'similarity': 1.0, 'mismatch': False,
                      'liveness': True, 'no_face': False}

          faces = self._app.get(frame)
          if not faces:
              return {'verified': False, 'similarity': 0.0, 'mismatch': False,
                      'liveness': True, 'no_face': True}

          face = faces[0]   # Use the most prominent face
          current_embedding = face.embedding

          with self._lock:
              if self._enrolled_embedding is None:
                  return {'verified': True, 'similarity': 1.0, 'mismatch': False,
                          'liveness': True, 'no_face': False}

              # Cosine similarity
              similarity = float(
                  np.dot(self._enrolled_embedding, current_embedding) /
                  (np.linalg.norm(self._enrolled_embedding) * np.linalg.norm(current_embedding))
              )

          mismatch = similarity < COSINE_THRESHOLD

          # Liveness check
          liveness = self._check_liveness(frame, face)

          return {
              'verified': not mismatch and liveness,
              'similarity': round(similarity, 4),
              'mismatch': mismatch,
              'liveness': liveness,
              'no_face': False
          }

      def _check_liveness(self, frame: np.ndarray, face) -> bool:
          """Run MiniFASNet liveness check. Returns True if live, False if spoof."""
          if self._liveness_session is None:
              return True   # Degrade gracefully if model not loaded

          try:
              bbox = face.bbox.astype(int)
              x1, y1, x2, y2 = bbox[0], bbox[1], bbox[2], bbox[3]
              face_crop = frame[max(0,y1):y2, max(0,x1):x2]
              if face_crop.size == 0:
                  return True

              face_crop = cv2.resize(face_crop, (80, 80))
              face_crop = face_crop.astype(np.float32) / 255.0
              face_crop = face_crop.transpose(2, 0, 1)[np.newaxis]

              input_name = self._liveness_session.get_inputs()[0].name
              outputs = self._liveness_session.run(None, {input_name: face_crop})
              # Output index 1 = live probability
              live_prob = float(outputs[0][0][1])
              return live_prob > 0.5
          except Exception as e:
              logger.debug(f"Liveness check error (non-critical): {e}")
              return True

      def reset(self):
          """Clear enrolled embedding at session end."""
          with self._lock:
              self._enrolled_embedding = None

PURPOSE: Detect multiple faces in frame. Uses temporal confirmation (3 seconds)
to prevent a single-frame false positive from flagging a legitimate candidate.

  import cv2
  import mediapipe as mp
  import threading
  import time
  import logging

  logger = logging.getLogger(__name__)

  TEMPORAL_CONFIRMATION_SECONDS = 3.0
  MIN_FACE_CONFIDENCE = 0.7

  class MultiFaceDetector:
      """
      Detects multiple faces using MediaPipe Face Detection.
      A multi-face flag is only raised if 2+ faces are visible
      continuously for TEMPORAL_CONFIRMATION_SECONDS.
      This eliminates false positives from brief occlusions or
      image artifacts.
      """

      def __init__(self):
          self._mp_face = mp.solutions.face_detection
          self._detector = self._mp_face.FaceDetection(
              model_selection=1,             # 1 = full range (up to 5m)
              min_detection_confidence=MIN_FACE_CONFIDENCE
          )
          self._lock = threading.Lock()
          self._multi_face_first_seen: float | None = None
          self._result = {
              'face_count': 0,
              'multiple_faces': False,
              'confirmed': False,
              'seconds_detected': 0.0
          }

      def analyze(self, frame) -> dict:
          """
          Process a BGR numpy frame.
          Returns detection result with temporal confirmation status.
          """
          rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
          results = self._detector.process(rgb)

          face_count = 0
          if results.detections:
              face_count = len(results.detections)

          now = time.monotonic()
          multiple = face_count >= 2

          with self._lock:
              if multiple:
                  if self._multi_face_first_seen is None:
                      self._multi_face_first_seen = now
                  seconds_active = now - self._multi_face_first_seen
                  confirmed = seconds_active >= TEMPORAL_CONFIRMATION_SECONDS
              else:
                  self._multi_face_first_seen = None
                  seconds_active = 0.0
                  confirmed = False

              self._result = {
                  'face_count': face_count,
                  'multiple_faces': multiple,
                  'confirmed': confirmed,
                  'seconds_detected': round(seconds_active, 1)
              }
              return dict(self._result)

      def check(self) -> dict:
          """Thread-safe read of last result."""
          with self._lock:
              return dict(self._result)

      def reset(self):
          with self._lock:
              self._multi_face_first_seen = None

          Useful for clipping only the speech parts for transcription.

          if not self._ready:

          return self.get_speech_timestamps(
              tensor, self._model,
              sampling_rate=SAMPLE_RATE,
              threshold=SPEECH_THRESHOLD
          )

PURPOSE: Maintain a rolling 30-second frame buffer. When a HIGH severity flag
is confirmed, extract an evidence clip (last 30s of video + audio) and upload
to MinIO for proctor review.

  import asyncio
  import io
  import time
  import logging
  import os
  from collections import deque

  import numpy as np
  import cv2
  import aiofiles
  import boto3
  from botocore.exceptions import ClientError

  logger = logging.getLogger(__name__)

  BUFFER_SECONDS = 30
  FPS = 10                      # Assumed pipeline frame rate
  BUFFER_MAXLEN = BUFFER_SECONDS * FPS
  MINIO_ENDPOINT = os.getenv('MINIO_ENDPOINT', 'http://localhost:9000')
  MINIO_ACCESS_KEY = os.getenv('MINIO_ACCESS_KEY', 'vera')
  MINIO_SECRET_KEY = os.getenv('MINIO_SECRET_KEY', 'vera_secret123')
  EVIDENCE_BUCKET = 'evidence-clips'


  class SessionRecorder:
      """
      Rolling frame buffer + evidence clip extraction.
      Frames are stored as JPEG bytes to minimize memory usage.
      A 30s buffer at 10fps uses ~30MB (1 frame ≈ ~100KB JPEG).
      """

      def __init__(self, session_id: str):
          self.session_id = session_id
          self._buffer: deque = deque(maxlen=BUFFER_MAXLEN)
          self._s3 = boto3.client(
              's3',
              endpoint_url=MINIO_ENDPOINT,
              aws_access_key_id=MINIO_ACCESS_KEY,
              aws_secret_access_key=MINIO_SECRET_KEY
          )
          self._ensure_bucket()

      def _ensure_bucket(self):
          try:
              self._s3.head_bucket(Bucket=EVIDENCE_BUCKET)
          except ClientError:
              try:
                  self._s3.create_bucket(Bucket=EVIDENCE_BUCKET)
                  logger.info(f"SessionRecorder: Created bucket {EVIDENCE_BUCKET}")
              except Exception as e:
                  logger.warning(f"SessionRecorder: Could not create bucket: {e}")

      def add_frame(self, frame: np.ndarray):
          """Add a BGR numpy frame to the rolling buffer."""
          _, jpeg = cv2.imencode('.jpg', frame, [cv2.IMWRITE_JPEG_QUALITY, 70])
          self._buffer.append({
              'ts': time.monotonic(),
              'data': jpeg.tobytes()
          })

      def extract_evidence_clip(self, flag_name: str) -> str | None:
          """
          Export current buffer as an MP4 and upload to MinIO.
          Returns the MinIO object key, or None on failure.
          """
          if not self._buffer:
              return None

          timestamp = int(time.time())
          key = f"{self.session_id}/{timestamp}_{flag_name}.mp4"
          tmp_path = f"/tmp/vera_evidence_{self.session_id}_{timestamp}.mp4"

          try:
              frames = list(self._buffer)
              h, w = cv2.imdecode(
                  np.frombuffer(frames[0]['data'], np.uint8),
                  cv2.IMREAD_COLOR
              ).shape[:2]

              writer = cv2.VideoWriter(
                  tmp_path,
                  cv2.VideoWriter_fourcc(*'mp4v'),
                  FPS, (w, h)
              )
              for f in frames:
                  img = cv2.imdecode(np.frombuffer(f['data'], np.uint8), cv2.IMREAD_COLOR)
                  writer.write(img)
              writer.release()

              self._s3.upload_file(tmp_path, EVIDENCE_BUCKET, key)
              os.unlink(tmp_path)
              logger.info(f"SessionRecorder: Evidence clip uploaded → {key}")
              return key
          except Exception as e:
              logger.error(f"SessionRecorder: Failed to save evidence clip: {e}")
              return None

      def reset(self):
          self._buffer.clear()

PURPOSE: Async PostgreSQL audit trail. Every behavioral flag, score update,
and session event is written to the database. Required for GDPR compliance
(Article 5 accountability principle) and for proctor review.

  import asyncio
  import os
  import time
  import logging
  import json

  import asyncpg

  logger = logging.getLogger(__name__)

  DB_URL = os.getenv(
      'VERA_DB_URL',
      'postgresql://vera_user:yourpassword@localhost:5432/vera_db'
  )

  CREATE_TABLES_SQL = """
  CREATE TABLE IF NOT EXISTS sessions (
      session_id      TEXT PRIMARY KEY,
      candidate_id    TEXT,
      exam_id         TEXT,
      started_at      TIMESTAMPTZ DEFAULT NOW(),
      ended_at        TIMESTAMPTZ,
      final_score     FLOAT,
      final_severity  TEXT,
      consent_given   BOOLEAN DEFAULT FALSE
  );

  CREATE TABLE IF NOT EXISTS behavioral_events (
      id              BIGSERIAL PRIMARY KEY,
      session_id      TEXT REFERENCES sessions(session_id),
      event_time      TIMESTAMPTZ DEFAULT NOW(),
      event_type      TEXT NOT NULL,
      severity        TEXT,
      risk_score      FLOAT,
      details         JSONB,
      evidence_key    TEXT
  );

  CREATE INDEX IF NOT EXISTS idx_events_session ON behavioral_events(session_id);
  CREATE INDEX IF NOT EXISTS idx_events_time ON behavioral_events(event_time);
  """

  class AuditLogger:
      """
      Async audit trail logger using asyncpg + PostgreSQL.
      All writes are fire-and-forget (non-blocking) to not slow the pipeline.
      """

      def __init__(self):
          self._pool = None
          self._ready = False

      async def initialize(self):
          """Call once at server startup."""
          try:
              self._pool = await asyncpg.create_pool(DB_URL, min_size=2, max_size=10)
              async with self._pool.acquire() as conn:
                  await conn.execute(CREATE_TABLES_SQL)
              self._ready = True
              logger.info("AuditLogger: PostgreSQL connection pool ready.")
          except Exception as e:
              logger.error(f"AuditLogger: DB init failed: {e}")
              logger.warning("AuditLogger: Running WITHOUT audit logging. Fix DB config.")

      async def log_session_start(self, session_id: str, candidate_id: str,
                                  exam_id: str, consent_given: bool):
          if not self._ready:
              return
          try:
              async with self._pool.acquire() as conn:
                  await conn.execute(
                      """INSERT INTO sessions (session_id, candidate_id, exam_id, consent_given)
                         VALUES ($1, $2, $3, $4) ON CONFLICT DO NOTHING""",
                      session_id, candidate_id, exam_id, consent_given
                  )
          except Exception as e:
              logger.error(f"AuditLogger.log_session_start: {e}")

      async def log_event(self, session_id: str, event_type: str,
                          severity: str, risk_score: float,
                          details: dict, evidence_key: str = None):
          if not self._ready:
              return
          try:
              async with self._pool.acquire() as conn:
                  await conn.execute(
                      """INSERT INTO behavioral_events
                         (session_id, event_type, severity, risk_score, details, evidence_key)
                         VALUES ($1, $2, $3, $4, $5, $6)""",
                      session_id, event_type, severity, risk_score,
                      json.dumps(details), evidence_key
                  )
          except Exception as e:
              logger.error(f"AuditLogger.log_event: {e}")

      async def log_session_end(self, session_id: str, final_score: float,
                                final_severity: str):
          if not self._ready:
              return
          try:
              async with self._pool.acquire() as conn:
                  await conn.execute(
                      """UPDATE sessions SET ended_at=NOW(),
                         final_score=$2, final_severity=$3
                         WHERE session_id=$1""",
                      session_id, final_score, final_severity
                  )
          except Exception as e:
              logger.error(f"AuditLogger.log_session_end: {e}")

      async def get_session_events(self, session_id: str) -> list:
          if not self._ready:
              return []
          async with self._pool.acquire() as conn:
              rows = await conn.fetch(
                  """SELECT * FROM behavioral_events
                     WHERE session_id=$1 ORDER BY event_time ASC""",
                  session_id
              )
          return [dict(r) for r in rows]

          record.ip_address = ip_address
          record.purposes_accepted = BIOMETRIC_DATA_PURPOSES if given else []

          action = 'GIVEN' if given else 'DECLINED'
          logger.info(f"ConsentManager: Consent {action} for session {session_id}")
          return {'success': True, 'consent_given': given, 'record': record.to_dict()}

      def is_consent_given(self, session_id: str) -> bool:
          """
          Check if consent has been given for this session.
          Returns False if no record exists or if consent was declined.
          The pipeline MUST check this before processing biometric data.
          """
          record = self._records.get(session_id)
          return record is not None and record.given

      def get_record(self, session_id: str) -> ConsentRecord | None:
          return self._records.get(session_id)

      def cleanup(self, session_id: str):
          self._records.pop(session_id, None)

[NEW FILE] vera/bias_calibrator.py

PURPOSE: CLAHE preprocessing for low-light equity (prevents darker-skinned
candidates from being penalized by lower face detection confidence in dim
lighting) and per-candidate adaptive baseline thresholds (each candidate's
own 30-second baseline is used as reference, not a universal fixed threshold).

  import cv2
  import numpy as np
  import time
  import logging
  from collections import deque

  logger = logging.getLogger(__name__)

  BASELINE_DURATION_SECONDS = 30
  CLAHE_CLIP_LIMIT = 2.0
  CLAHE_TILE_SIZE = (8, 8)


  class BIASCalibrator:
      """
      Two functions:
      1. CLAHE preprocessing — normalizes frame brightness before CV processing.
         Equitable across skin tones and lighting conditions.
      2. Adaptive baseline — collects each candidate's personal behavioral
         baseline for the first 30 seconds. All subsequent thresholds are
         relative to this baseline, not fixed universal values.
      """

      def __init__(self):
          self._clahe = cv2.createCLAHE(
              clipLimit=CLAHE_CLIP_LIMIT,
              tileGridSize=CLAHE_TILE_SIZE
          )
          # Baseline collection
          self._collecting = False
          self._baseline_start: float | None = None
          self._gaze_samples = deque(maxlen=300)   # 30s × 10fps
          self._emotion_samples = deque(maxlen=300)
          self._baseline: dict | None = None

      def preprocess_frame(self, frame: np.ndarray) -> np.ndarray:
          """
          Apply CLAHE to the luminance channel for lighting normalization.
          Input/output: BGR numpy array.
          """
          lab = cv2.cvtColor(frame, cv2.COLOR_BGR2LAB)
          l, a, b = cv2.split(lab)
          l_eq = self._clahe.apply(l)
          lab_eq = cv2.merge([l_eq, a, b])
          return cv2.cvtColor(lab_eq, cv2.COLOR_LAB2BGR)

      def start_baseline_collection(self):
          """Call at session start. Collects 30s of normal behavior."""
          self._collecting = True
          self._baseline_start = time.monotonic()
          self._gaze_samples.clear()
          self._emotion_samples.clear()
          self._baseline = None
          logger.info("BiasCalibrator: Baseline collection started.")

      def feed_sample(self, gaze_score: float, emotion_distress: float):
          """Feed each pipeline tick's scores during baseline collection."""
          if not self._collecting:
              return

          self._gaze_samples.append(gaze_score)
          self._emotion_samples.append(emotion_distress)

          elapsed = time.monotonic() - self._baseline_start
          if elapsed >= BASELINE_DURATION_SECONDS:
              self._finalize_baseline()

      def _finalize_baseline(self):
          gaze_arr = np.array(self._gaze_samples)
          emotion_arr = np.array(self._emotion_samples)

          self._baseline = {
              'gaze_mean': float(np.mean(gaze_arr)),
              'gaze_std': float(np.std(gaze_arr)),
              'emotion_mean': float(np.mean(emotion_arr)),
              'emotion_std': float(np.std(emotion_arr)),
              # Adaptive threshold = personal mean + 2 standard deviations
              'gaze_threshold': float(np.mean(gaze_arr) + 2 * np.std(gaze_arr)),
              'emotion_threshold': float(np.mean(emotion_arr) + 2 * np.std(emotion_arr)),
          }
          self._collecting = False
          logger.info(f"BiasCalibrator: Baseline finalized: {self._baseline}")

      def is_baseline_ready(self) -> bool:
          return self._baseline is not None

      def get_adaptive_thresholds(self) -> dict:
          """
          Returns thresholds calibrated to this specific candidate.
          Use these instead of fixed universal thresholds in the pipeline.
          """
          if self._baseline is None:
              # Fall back to conservative defaults if baseline not yet collected
              return {'gaze_threshold': 0.6, 'emotion_threshold': 0.5}
          return {
              'gaze_threshold': self._baseline['gaze_threshold'],
              'emotion_threshold': self._baseline['emotion_threshold']
          }

      def reset(self):
          self._collecting = False
          self._baseline_start = None
          self._gaze_samples.clear()
          self._emotion_samples.clear()
          self._baseline = None

[NEW FILE] static/js/session.js

PURPOSE: Client-side session lifecycle management. Handles session
initialization, state tracking across pages, and guaranteed cleanup on
page unload / navigation.

  /**
   * VERA SessionManager
   * Manages client-side session state and WebSocket lifecycle.
   * Call SessionManager.init() on every page.
   * Call SessionManager.start(mode) when a session begins.
   * Call SessionManager.destroy() on disconnect / page unload.
   */

  const SessionManager = (() => {
    const SESSION_KEY = 'vera_session';
    let _ws = null;
    let _sessionId = null;
    let _mode = null;
    let _onMessage = null;
    let _onFlag = null;
    let _reconnectTimer = null;
    const MAX_RECONNECT_ATTEMPTS = 3;
    let _reconnectAttempts = 0;

    function init() {
      window.addEventListener('beforeunload', destroy);
      window.addEventListener('visibilitychange', () => {
        if (document.hidden && _ws) {
          _sendEvent('TAB_SWITCH');
        }
      });
    }

    function start(mode, sessionId = null) {
      _mode = mode;
      _sessionId = sessionId || crypto.randomUUID();
      sessionStorage.setItem(SESSION_KEY, JSON.stringify({
        id: _sessionId,
        mode: _mode,
        startedAt: Date.now()
      }));
      return _sessionId;
    }

    function connectWebSocket(url, { onMessage, onFlag, onDisconnect } = {}) {
      _onMessage = onMessage;
      _onFlag = onFlag;
      _ws = new WebSocket(url);

      _ws.onopen = () => {
        console.log('[VERA] WebSocket connected. Session:', _sessionId);
        _reconnectAttempts = 0;
        _ws.send(JSON.stringify({
          type: 'SESSION_INIT',
          sessionId: _sessionId,
          mode: _mode
        }));
      };

      _ws.onmessage = (event) => {
        const data = JSON.parse(event.data);
        if (data.severity === 'HIGH' && _onFlag) {
          _onFlag(data);
        }
        if (_onMessage) _onMessage(data);
      };

      _ws.onclose = () => {
        if (_reconnectAttempts < MAX_RECONNECT_ATTEMPTS) {
          _reconnectAttempts++;
          _reconnectTimer = setTimeout(() => {
            connectWebSocket(url, { onMessage, onFlag, onDisconnect });
          }, 2000 * _reconnectAttempts);
        } else if (onDisconnect) {
          onDisconnect();
        }
      };

      _ws.onerror = (err) => {
        console.error('[VERA] WebSocket error:', err);
      };

      return _ws;
    }

    function sendFrame(base64Frame) {
      if (_ws && _ws.readyState === WebSocket.OPEN) {
        _ws.send(JSON.stringify({ type: 'FRAME', data: base64Frame }));
      }
    }

    function sendAudio(base64Audio) {
      if (_ws && _ws.readyState === WebSocket.OPEN) {
        _ws.send(JSON.stringify({ type: 'AUDIO', data: base64Audio }));
      }
    }

    function _sendEvent(eventType, payload = {}) {
      if (_ws && _ws.readyState === WebSocket.OPEN) {
        _ws.send(JSON.stringify({ type: 'EVENT', event: eventType, ...payload }));
      }
    }

    function destroy() {
      clearTimeout(_reconnectTimer);
      if (_ws) {
        _ws.onclose = null;   // Prevent reconnect on deliberate destroy
        _ws.close(1000, 'Session ended');
        _ws = null;
      }
      sessionStorage.removeItem(SESSION_KEY);
      _sessionId = null;
      _mode = null;
      _reconnectAttempts = 0;
    }

    function getSessionId() { return _sessionId; }
    function getMode() { return _mode; }

    return { init, start, connectWebSocket, sendFrame, sendAudio, destroy,
             getSessionId, getMode };
  })();

  # MinIO Standalone Binary Setup (No Docker)

  ## Why no Docker?
  Docker Desktop requires a paid licence for commercial use on Mac/Windows
  for companies with >250 employees or >$10M revenue. The MinIO standalone
  binary is Apache 2.0 and runs directly — no Docker, no dependencies.

  ## Linux Server (recommended for production)
  wget https://dl.min.io/server/minio/release/linux-amd64/minio
  chmod +x minio
  sudo mv minio /usr/local/bin/minio

  # Create systemd service for auto-start:
  sudo tee /etc/systemd/system/minio.service > /dev/null <<EOF
  [Unit]
  Description=MinIO Object Storage
  After=network.target
  [Service]
  User=www-data
  Environment="MINIO_ROOT_USER=vera"
  Environment="MINIO_ROOT_PASSWORD=vera_secret123"
  ExecStart=/usr/local/bin/minio server /data --console-address :9001
  Restart=always
  [Install]
  WantedBy=multi-user.target
  EOF

  sudo systemctl daemon-reload
  sudo systemctl enable minio && sudo systemctl start minio
  # API: http://localhost:9000   Console: http://localhost:9001

  ## macOS
  brew install minio/stable/minio
  MINIO_ROOT_USER=vera MINIO_ROOT_PASSWORD=vera_secret123 minio server ~/minio-data --console-address :9001

  # Tailwind CSS Standalone CLI Setup

  ## Why not the play CDN?
  Tailwind's own docs say: "The Play CDN is designed for development only."
  It runs JS at runtime (~300KB), is slow, and sends telemetry.
  The standalone CLI compiles to a local minified CSS file. No Node.js needed.

  ## Download

  # Linux:
  curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64
  chmod +x tailwindcss-linux-x64 && mv tailwindcss-linux-x64 tailwindcss

  # macOS (Apple Silicon):
  curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-macos-arm64
  chmod +x tailwindcss-macos-arm64 && mv tailwindcss-macos-arm64 tailwindcss

  # Windows: download tailwindcss-windows-x64.exe from GitHub releases

  ## Compile
  ./tailwindcss -i static/css/input.css -o static/css/vera.css --minify

  ## Development (watch mode)
  ./tailwindcss -i static/css/input.css -o static/css/vera.css --watch

  ## After compilation
  Prepend the @font-face and @keyframes from vera-custom.css to vera.css.
  Or use a build script:
    cat vera-custom.css > static/css/vera.css
    ./tailwindcss -i static/css/input.css >> static/css/vera.css --minify
